## Method

- Blind run: First blind run. Predictions were produced by commit cd55ed3 (before the shortlist fix in 60bbddb) and are scored here from the stored file; the commit and prompt versions in 'provenance' are those at scoring time.
- Scored at commit `f986f39334`; models {'llm_fast_model': 'gemini-3.1-flash-lite', 'llm_strong_model': 'gemini-3.5-flash-lite'}; prompt versions {'clause_selection': 'v2', 'extraction': 'v2', 'recommendation': 'v1'}. Frozen test set hash check passed: True.
- The pipeline was tuned on the 40-claim dev set only. The 160-claim test set was run once before any fix derived from it.
- Intervals are 95% bootstrap intervals over claims.
- Pilot rules (stated in advance): first claim of each tester per round dropped; sessions with an idle gap over 5 minutes dropped; median time per mode with N; override rate on assisted decisions only. Protocol in `docs/pilot/README.md`.

## Limitations

- **Synthetic, templated data.** Accuracy says the pipeline handles this generator, not real paperwork.
- **Small positive counts.** 18 fraud-flagged test claims; 100% recall on 18 is encouraging, not tight.
- **Not blind any more** for the shortlist fix, which came from reading the blind run's errors (`docs/error-analysis.md`); any later test-set number is post-hoc.
- **Estimated costs** from assumed prices; not checked against a billing page.
- **Pilot size.** 3 to 5 testers is a pilot, not a study; one claim type; synthetic claims.
- **OCR differs by platform**; scores were recorded on macOS Tesseract, and CI replays inside the Linux image.

## Reproduce

```bash
cd backend && LLM_MODE=replay uv run python -m app.pipeline.evalcli analyze --extractions ../eval/results/preds_extract_test.json --out ../eval/results/preds_pipeline_test.json
cd ../eval && uv run python -m harness.report --split test --predictions results/preds_pipeline_test.json --name offline_test_posthoc
uv run python -m pilot.analyze pilot/raw/sessions_v1.0.csv --feedback pilot/raw/feedback_v1.0.csv --out results/pilot_v1.0.json
uv run python make_results.py
```
